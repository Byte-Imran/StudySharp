# studySharp Client

The studySharp frontend is a React application built with Vite. It uses Tailwind CSS, Redux Toolkit, React Router, and Axios.

## Development

- `npm run dev` starts the local development server.
- `npm run build` creates the production build.
- `npm run lint` checks the source code with Oxlint.

Use `LazyImage` from `src/components/LazyImage.jsx` for images that should load near the viewport. Provide image dimensions when possible to reduce layout shifts.
